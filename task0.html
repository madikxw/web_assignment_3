Responsive Typography

The font size of this page changes depending on the screen width: small on mobile, medium on tablet and larger on desktop.

What are media queries?

Media queries are a CSS feature that applies styles only when certain conditions are met, for example when the viewport is wider than a given number of pixels.

Breakpoints used

Mobile: up to 767px. Tablet: 768px to 991px. Desktop: 992px and wider.
